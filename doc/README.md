## 🛠️ 技术栈

本项目采用现代化前端技术栈：
- **Vue 3** - 响应式框架（Composition API）
- **Vite** - 构建工具
- **Tailwind CSS** - 原子化CSS框架
- **JavaScript ES6+** - 现代JavaScript
